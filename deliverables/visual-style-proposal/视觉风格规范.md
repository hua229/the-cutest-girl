## 1. 美学定位

把界面当成一本两人共写、摊开的布面手账：页面是中性米纸，内容是被「贴」上去的纸片，粉色只以盖章 / 印泥的身份出现。目标是**更暖更软，但不更甜**——暖来自纸基色温与暖墨影，软来自圆角与留白，不来自加粉。

**纸感落到二维界面的六条手段**（不引图片资源、不引字体文件、不用 emoji）：

1. 底色分档：页面 / 卡面 / 抬升三级，靠 1.101:1（浅）、1.108:1（深）明度差 + 1dp 实色纸边分界。
2. 程序化纸纤维：Canvas 6dp×6dp 网格散点 + 12dp 横向纤维线，固定种子 `20240611`，密度 ≤3%，静态绘制 + 坐标缓存。
3. 装订线：三大模块主页左缘 `x=12dp` 1dp 竖虚线 `dash(6,4)` + 3 个 Ø4dp 装订孔（内容高 25% / 50% / 75%）；设置页与弹层不出现。
4. 胶带 / 贴纸：48×16dp、旋转 −3°、圆角 2dp 的半透明纸胶带，仅纪念日卡与空态卡、全屏 ≤1 条；三餐「早/午/晚」用 20dp 高、圆角 4dp、旋转 −1.5° 的近方角纸质标签。
5. 手账式分隔：区块之间用 1dp `dash(6,4)` 虚线替代实线 Divider，左右内缩 16dp；空态卡四角各 1 个 4×4dp 十字针脚。
6. 留白节奏：卡间距 20dp、卡内 16dp、段落 12dp、Section 32dp。

**与 v4.0 的对照**：v4.0 是「色彩主题」（大面积粉相底 H≈345° + 紫调深色 H≈290° + 玻璃发光）；本方案是「材质主题」（浅底 H39° 无粉相、深底 H24–30° 无紫、粉色仅 6 位、装饰来自针脚 / 胶带 / 虚线 / 纤维）。

| 组合 | 最紧值 | 使用限制 |

## 4. 形状与间距

- **圆角**：控件 10（原 8）｜卡片 12（原 16，更接近裁纸）｜容器·抽屉·弹层 20（原 24）｜胶囊 999｜FAB / 圆按钮 50%｜贴纸标签 4｜胶带 2。统一表述：**贴边侧直角、露出侧 20dp** —— 左侧抽屉左上左下直角、右上右下 20dp；底部 AddRecordSheet 上两角 20dp。
- **控件高度**：主按钮 48、次按钮 40、FAB 56、顶栏 56、底栏 64、列表行 56、输入框 48、分段 40、SyncStatusBar 32、空态卡 120、贴纸标签 20。
- **间距网格**：4 / 8 / **12**（新增）/ 16 / 24 / 32 / 48。页边距 24、卡内 16、卡间距 **20**（原 16）、段落 12、Section 32、页底 48；照片格间距 4（穿搭月视图）/ 8（饮食·事件）。
- **20dp 的强制判定规则**：仅用于**页面级独立卡 / Section 之间**；同一列表、同一网格、卡内相邻元素仍 16 / 4 / 8dp；纪念日卡 ↔ 点滴列表强制 **32dp Section**。误把 20dp 套进 3 列网格会让月视图每屏少显示约一行照片。
- 边框从 1dp 半透改为 **1dp 实色**；穿搭月卡左缘加 3dp hairline 压痕。

## 5. 材质与层次

| 层 | 浅色 | 深色 |
| --- | --- | --- |
| 卡片 fill | `#FCF8F1` **100% 不透明**（取消 92% 玻璃、取消一切模糊） | `#221E1A` 100% |
| 纸边 | 1dp 全周 `#E2D6C2` | 1dp `#3B332C` |
| 顶缘高光 | 1dp `#FFFCF7`（cardGlow） | 1dp `#4A4038`@45%（合成 `#342D28`） |
| 左缘压痕 | 1dp `#D6C8B2` 暗线 | 1dp `#14100E` |
| 投影 | y=2dp / blur=6dp `#6B5B45`@8%（暖墨影） | **无投影**，靠明度差 + 1dp 边 + 内发光承担 |

**纸质纹理**：Canvas 静态绘制 + 缓存，6dp×6dp 单元固定种子 `20240611` 画 1 个 Ø0.6dp 点（浅 `#8A7A62`@2.5% / 深 `#C9B79B`@3%），每 12dp 一条 0.5dp 横线；纹理层位于 fill 之上、border 之下，文字最后绘制且不叠纹理。最坏情况复算：浅辅文字 4.91→4.78、深 7.31→6.97，仍 ≥4.5。

**底栏**：从「液态玻璃 Haze」改为 **64dp 纸质横条**（浅 `#FBF6EC` / 深 `#201B17`）+ 1dp 纸边 + 1dp hazeGloss 顶光，与页面同纹理，**取消模糊与玻璃高光**；3 项与入口形态不变。`hazeTint` / `hazeGloss` 键名保留、只改值。

**AppPalette 13 个现有 token**（键名不变、只换两套值）：`hairline`、`mutedText`、`accentText`、`cardGlow`、`dashedFill`、`buttonFill`、`chromeTop`、`pillHighlight`、`pillEdge`、`hazeTint`、`hazeGloss`、`shadowAmbient`（代码字段 `shadowAmbientAlpha`）、`shadowSpotAlpha`。配套换值：`success`、`scrim`。功能色与中性面作为**数据登记**进 `LocalAppPalette`，不改组件读取方式、不加依赖。`paperInk`（浅 `#8A7A62` / 深 `#C9B79B`）为唯一新增**建议**字段，本轮不落代码；回退用 `mutedText`（浅 `#6E655A` / 深 `#ADA293`）作墨料，对比度复算仍达标。

| `SyncStatusBar` | 32dp、Ø8dp 状态点 + 14sp secondary 中文文字（必须含状态词）、失败原因允许 2 行；交互热区补足 48dp；**状态语义与文案不变，仅改色** |

**五态**：default / pressed（98% 缩放或 6% pressTint）/ disabled（实色底 + 实色 secondary 字，不降 alpha）/ error（1dp 错误边 + 14sp 中文说明）/ focused（2dp accent 描边、每屏焦点唯一）。

## 7. 体验规范

### 7.1 信息架构（零新增）

### 7.3 小屏与响应式

- **三档宽度**（内容宽 = 屏宽 − 48dp）：320dp → 内容 272dp、穿搭 3 列格宽 88dp、2 列格宽 132dp；360dp → 312 / 101.3 / 152dp；411dp → 363 / 118.3 / 177.5dp。标题阈值：屏宽 <360dp 用 28sp，≥360dp 用 30sp。
- **48sp 纪念日 4 位数字**：约 160dp（含「第/天」与间距）< 320dp 下卡内可用 237dp，**单行确定成立，不换行不缩字**。
- **卡间距 16→20dp 膨胀**：典型每屏 3–5 张独立卡 → +8~16dp，相对 640dp 可用高约 1.3–2.5%，不会挤出首屏，页底 48dp 不需回收。
- **键盘弹起（所有屏宽都需要重算，不是小屏特例）**：无键盘态 = 82% 屏高且 ≥360dp；IME 可见态 = 取「IME 之上可用高度」与 82% 的较小值，**360dp 下限失效**、兜底 ≥240dp；可用高 <240dp 时**同一 Sheet** 切全屏表单态（无遮罩、无上两角圆角、顶部「取消/保存」），不新增入口；字段区独立滚动 + 焦点自动滚入 + 主按钮吸底在 IME 之上；把手/标题固定；照片选择改 2 列换行，不嵌套同向滚动。

### 7.4 无障碍

- **触控热区 ≥48dp**：Ø4dp 装订孔热区 0 且点击穿透；Ø8dp 状态点、32×4dp 把手、32dp 状态条、40dp 次按钮/分段、24dp 图标一律补足；底栏整格约 106×64dp。
- **200% 动态字体**：所有写死高度改「最小高度 + 内容自适应」；纪念日大数字独占一行、上限 88sp / 下限 72sp、禁止截断与省略号；装饰尺寸用 dp 不随 sp 放大；底栏隐藏文字标签只留图标 + 读屏文案；顶栏 minHeight ≥80dp；文字与胶带/装订孔重叠时该装饰自动隐藏。
- **读屏与焦点**：全部中文；装饰层不发声、不可聚焦、不消费指针事件；照片给中文内容描述；「第 100 天」合并语义单元朗读；焦点可见 2dp accent 描边且每屏唯一；抽屉为模态、焦点困在抽屉内，关闭后回到菜单按钮。
- **色彩不得作为唯一信息载体**：状态点配文字、抽屉选中用竖条 + 文字色双重编码、错误态配中文说明、禁用态配读屏播报「不可用」。
- **白字例外白名单**收窄为 2 处且带暗底 / 描边；任何纸面浮层（空态卡、普通卡、抽屉、状态条、分段、确认弹层）一律不得出现白字或黑底。

### 7.5 装饰可用性

通用防线（强制）：装饰 ① 绘在内容下层；② 不设 clickable / 不消费指针事件；③ 不设焦点、不发声；④ 无 pressTint、无 98% 缩放、无焦点框；⑤ 与 48dp 热区重叠时热区归功能控件；⑥ 不参与任何动效。

| 装饰 | 允许位置 | 每屏上限 | 禁止位置 |
| --- | --- | --- | --- |
| 装订线 + 3 孔 | 仅三大模块主页左缘 0–24dp 页边留白区 | 1 组 | 设置页、Sheet、大图、空态卡内、列表项内、任何 48dp 热区内 |
| 胶带 | 仅空态卡或纪念日卡顶缘一角 | ≤1 / 全屏 | 主按钮、输入框、状态条、照片浮层、文字行内 |
| 1dp 虚线分隔 | Section / 卡片组之间 | ≤3 条 | 列表项之间、文字行内、按钮内 |
| 四角针脚 | 仅 120dp 空态虚线卡 | 1 组 | 普通卡片、可点按钮、照片格 |
| 三餐纸质标签 | 仅饮食页三段标题左侧 | 1 组（3 处） | 作为按钮、照片上、评论区、设置页 |
| 程序化纸纹 | 仅页面底与卡面，内容下层 | 密度 ≤3% | 文字上层、照片上、输入框文字区、图标上 |
| 左缘 3dp 渐变光 | 仅纪念日数字卡左缘 | ≤1 / 屏 | 普通卡片、抽屉选中行 |

**高对比模式统一降级**：纸纹（L1）、渐变光（L2）、胶带（L3）、针脚（L5）、虚线改实线（L7）强制关闭；抽屉展开时主页装饰隐藏，避免与抽屉装订孔叠影。

### 8.2 性能验收硬线

- **纸纹**：静态一次性绘制 + 坐标缓存，禁止逐帧重算、禁止换档重新播种；绘制顺序 fill → 纹理 → 1dp 边/高光/压痕 → 文字；纹理与 fill 合并同一 draw pass，不新增独立全屏 layer。
- **阈值**：全屏平均 overdraw ≤2.0x、任何区域 ≤3.0x；单帧 `Draw` P95 ≤4.0ms / P99 ≤8.0ms；600 帧内超时帧 ≤6 帧、掉帧率 ≤1%；滚动期间纹理相关重组 = 0；换档后坐标缓存复用率 100%。
- **净评估（确定）**：去 Haze 移除的是「每帧持续 GPU 开销」（离屏 FBO + 32dp 模糊 + 噪点采样），新增纸纹是「一次性 Canvas 绘制 + 缓存读取」，**净收益为正，不需要回滚，也不需为纸纹追加帧预算**。
- **换档核对**：无 `Activity.recreate()` / 无 configuration change；表单与 `LazyListState` 不丢；纸纹只换墨料色；220ms 淡入不做交叉溶解；系统栏图标同帧翻转无闪白闪黑。已知限制：手动深色 + 机身浅色冷启动约一帧浅底，`values-night` 只跟机身 uiMode，**明确接受**，不采用会丢表单的 AppCompat 重建。
- **降级工程实现**：单一 `DegradationLevel`（L0–L8）+ `LocalDegradationLevel` 集中驱动，组件内不写机型判断、不散落 if；性能触发 = 连续 3 个 100ms 窗口 P95 >16.7ms 或 >3.0x overdraw 区域占屏 >20%，一次降一级 + 500ms 冷却与回滞；高对比模式 / `fontScale ≥ 2.0` 时 L1/L2/L3/L5/L7 一次性强制生效、不可被性能回升覆盖。
- **降级优先级**：L1 关纸纹 → L2 渐变光改实色/隐藏 → L3 隐藏胶带 → L4 隐藏装订孔 → L5 隐藏针脚 → L6 三餐标签拉直 → L7 虚线改实线 → L8 隐藏装订线。**不可降级**：纸卡不透明 + 实色边、48dp 热区、对比度、五态、反馈三分、中文文案与读屏、焦点可见、键盘避让、换档不丢状态、白字白名单、装饰不发声、单一入口与信息结构。
