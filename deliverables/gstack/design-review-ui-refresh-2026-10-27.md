## 1. 各成员核心结论

### 🎨 设计师（设计系统审查）
- 核心判断："视觉语言已经成熟，但设计系统只存在于文案里"——配色和字重层级规范很好，但圆角/间距/组件尺寸全部硬编码散落 9 个文件，所有不一致都是这个根因的症状；最大破口是三页三种头部结构，用户每天感知最强；状态模型只有 1/4（只有空态，照片占位"同步中/失败"不可区分）。
- 关键建议：建 Design Token（圆角 4 档 + 间距 4dp 基数 + displaySmall 字号）→ 统一三页头部为两段式 → 抽 AppCard/DateFieldRow/PhotoPlaceholder/StatusLine 公共组件；给出完整的"不要做"反模式清单（不加卡片阴影、不扩大玫瑰色面积、不引新图标库、不动 Haze 参数、不开 dynamicColor 等）。
- 完整产出要点：P0 8 项 / P1 6 项 / P2 4 项 + 四批实施顺序。

### 🔍 产品官（产品评审）
- 核心判断：这是"靠同步维系的两人情感产品"，隐含承诺是"ta 记的 ≤15 分钟你会知道"——UI 最大缺口都围绕这条承诺；照片占位歧义是**信任级缺口**（挂在原地不动的话用户会怀疑"她没发/APP 坏了"）；通知落地错位让产品最高光的时刻变成"找东西"；穿搭页只能逐月点箭头、回看成本随时间线性上涨。
- 关键建议：小步快跑一轮只做 3 处（全部用户每天感知），不做系统性重构；明确区分"用户价值"与"工程洁癖"（字号/圆角/组件去重用户零感知，攒到设计系统专项轮）；推翻 1 条候选（穿搭 4:5 vs 饮食裁切是内容类型决定的合理差异，不统一）；补充 2 个新断点（月份跳转、通知 deeplink）。
- 完整产出要点：用户旅程走查 4 环节、6 条验收标准、6 个拍板问题、分批降险顺序与回滚触发条件。

## 3. 本轮实施方案（P0 三件套 + 捎带，分 3 批独立交付）

**实施顺序（风险从低到高，每批独立 commit + 独立 versionCode）**：
批次一（设置页·最低风险）→ 批次二（照片占位·组件级替换）→ 批次三（头部统一·布局重排，风险最高放最后）。

### 批次一：设置页状态清晰化（SettingsScreen.kt）
- 新增状态条组件：`Surface(发丝描边圆角卡) { Row { 状态图标 + Column{ 主状态文案; 上次同步信息 } } }`
- 连接成功 → `Icons.Outlined.CheckCircle` + 主色 + "同步已开启"；连接失败 → `Icons.Outlined.CloudOff` + error 色 + "连接失败：请检查账号和应用密码"；测试中 → 16dp CircularProgressIndicator + "正在测试连接…"；已入队 → `Icons.Outlined.Schedule` + "已加入同步队列，联网时马上执行"
- 上次同步信息升为状态条副行："上次同步：M月d日 HH:mm · 成功/失败"（结果词成功用主色、失败用 error 色）
- 顺手：被改到的行的硬编码 fontSize（13/12sp）换 labelMedium/labelSmall，只动本来就要动的行
- 通知里的 💗 保留（系统通知是产品情感签名，不属于 UI 禁 emoji 范畴）

### 批次二：照片占位可区分可重试（Common.kt + 三个列表页）
- 新增共享组件 `PhotoSyncPlaceholder(height/aspectRatio, failed, onRetry)`，替换三处复制粘贴的"照片同步中…"Box（OutfitScreen:160-172 / MealScreen:339-352 / EventScreen:268-280）——唯一值得顺手做的去重，因为本来就要重写
- 视觉：极浅玫瑰底（primary 6% 透明度），居中竖排 CloudSync/CloudOff 图标 + 两行文案；**尺寸跟随原位**（穿搭 4:5、饮食 90dp、事件 110dp，不趁机统一）
- 两态：同步中（默认）"照片还在路上…/同步完成后会自动出现"；同步不了（启发式：lastSyncResult 为失败或无网络）"现在同步不了/点一下重新同步"。**最多两态，不做状态机**
- 占位卡永远可点击 → `SyncManager.enqueueNow(context)`（同步幂等 + Mutex 串行，重试无副作用），点击后 Toast"已开始同步，照片稍后出现"——必须给即时反馈

### 批次三：三页头部统一 + 穿搭页月份跳转（三个 Screen）
- **第 1 行·标题行（三页完全一致，永久静止）**：`Row { Column(weight 1f){ headlineMedium 标题; labelMedium 副标题 }; IconButton(Settings 固定最右) }`——不放任何条件出现/消失的控件
- **第 2 行·日期条（穿搭+饮食结构对齐；事件页为时间线无日期过滤，不设第 2 行）**：`Row { IconButton(◀) + 居中可点区域(weight) + IconButton(▶) }`
- 饮食页："回到今天"从标题行挪进日期条居中区第二行小字（今天→"今天"主色徽标；非今天→可点"回到今天"）
- 穿搭页：中间"2026年10月"可点击 → 弹轻量月份选择弹窗（◀ 年份 ▶ + 3×4 月份网格，选中态主色 14% 胶囊底与底栏指示器同语言，约 60-80 行自定义 Compose）；非本月时同样加"回到本月"小字
- 统一各页 top padding（10dp→12dp）；三页**必须同轮完成，不可半统一**
- 边缘情况清单：长昵称/长副标题换行、小屏挤叠、日期条与 LazyColumn contentPadding 衔接、玻璃底栏 inset 对齐不变

### 捎带项：启动图标底色
- colors.xml:3 `#E58BA7` → 玫瑰主色系（`#B25A79` 或微调后的 `#BE6E8B`，以自适应图标实测效果为准），零代码风险
