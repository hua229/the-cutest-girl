# 设计系统（v5.0.0，iOS 风格）

> 2026-11-25：克制的 iOS 视觉、低饱和玫粉点缀、实色内容表面与悬浮玻璃导航；统一磨砂新增图标并精简装饰文案。当前版本 5.0.0（versionCode 46），沿用 4.3.1 固定证书；验证结果与两阶段范围见第 8 节。

## 1. 色彩与主题

| 角色 | 浅色 | 深色 |
| --- | --- | --- |
| 页面底 | `#F5F5F7` | `#111114` |
| 内容卡面 | `#FFFFFF` | `#1D1D22` |
| 控件底 | `#F0F0F4` | `#2A2A31` |
| 主文字 | `#202027` | `#F1F1F5` |
| 辅助文字 | `#686871` | `#B4B4BF` |
| 主色 | `#AF4F70` | `#E7A8BF` |
| 选中容器 | `#F4E6EC` | `#49303D` |

页面、卡片和文字以中性色为主，玫粉用于主操作、选中状态与少量纪念日重点。成功、警告、错误按语义使用颜色，避免把大面积背景做成粉色。

- `ThemeMode` 提供「跟随系统 / 浅色 / 深色」三档，缺失或非法存储值默认为跟随系统；已有合法值沿用。
- `ThemeStore.mode` 是 `StateFlow`，偏好保存在本机 `settings.xml/theme_mode`，不参与记录同步或 ZIP 身份备份。
- `Theme.kt` 为两套 Material `ColorScheme` 显式提供完整表面层级，新增槽位必须同时考虑浅深两套。
- `AppPalette` / `appPalette` 只承载 Material 没有槽位的材质：`hairline`、`glassSurface`、`glassHighlight`、`glassEdge`、`glassShadow`、`pillBody`、`pillHighlight`、`pillEdge`、`scrim` 和 `isDark`。业务表面与文字读 `MaterialTheme.colorScheme`。
- 大图查看器保持黑底白控件；覆盖在照片上的移除按钮保持固定对比，不随页面主题翻转。

## 2. 排版与形状

- 使用 `FontFamily.Default` 跟随设备系统字体，所有 `sp` 字号跟随系统缩放，不捆绑 SF 字体。页面大标题 32sp Semibold、正文 17sp、辅助 14sp、角标与底栏标签 12sp。
- 日期和纪念日数字使用系统字形与 `fontFeatureSettings = "tnum"`，不再使用 Monospace；纪念日主要数字 44sp Medium。
- 形状 token：小控件 12dp、内容卡片 20dp、浮层 24/32dp。主按钮圆角 14dp，胶囊按自身尺寸决定圆角。
- 页面内容左右通常 20dp、卡内 16dp；按 4/8/12/16/20/24/32dp 组织间距。
- 普通操作热区至少 48dp；主按钮最小高 52dp、次按钮最小高 48dp。大字体允许内容增高，避免用固定高度裁掉文字。

## 3. 页面与导航

- 保留「穿搭 / 饮食 / 点滴」三主栏及原有记录、评论、同步、通知定位与状态恢复。
- 三个主页统一为左侧大标题、右侧「设置 / 新增」按钮；滚动时标题收缩，设置和新增入口仍可访问。去掉旧侧边设置抽屉及重复的底部新增入口。
- 穿搭保留月份与日期条，照片为主要视觉内容；饮食保留日期与早午晚记录，通过新增按钮选择餐次；点滴区分纪念日数字卡和日常记录。
- 三个主页的设置按钮进入同一 `settings` 首页。设置首页分组展示「我的信息 / 外观」及「云同步 / 数据备份 / 后台不被冻结」。
- 五个模块保持独立路由：`settings/profile`、`settings/appearance`、`settings/sync`、`settings/backup`、`settings/battery`。返回模块首页后再返回原主页，不新增第四个底栏标签。
- 照片选择、草稿、上传人/对方权限、删除确认、备份恢复和同步状态原样保留。
- 文案只保留识别、操作与判断所需的信息：移除主页标语、装饰性副标题、输入示例、重复的日期/类型说明和次要尾标签。真实作者、字段名称、日期、数量限制、状态、错误与确认后果继续显示；同步配置帮助通过按需入口提供。
- 设置首页保留昵称、当前外观与实际同步运行/完成/失败等状态；空闲或尚未配置时不重复显示「已开启 / 未开启」，后台权限未开启时不再额外显示「去设置」尾标签。模块内的实际操作入口和权限状态仍保留。

## 4. 组件与材质

| 组件 | 当前规范 |
| --- | --- |
| `glassPanel` / `GlassCard` / `solidCard` | 保留名称兼容既有调用；默认是 100% 实色内容表面，20dp 圆角、无阴影、无描边，无顶部内发光；可显式开启发丝边框 |
| `PageHeader` / `FloatingTopBar` | 页头只呈现大标题与右侧设置/新增；`PageHeader` 使用 `title`、`collapsed`、`onClick`、`onOpenSettings`、`onAdd` 和 `modifier`，保留滚动收缩和回顶部交互 |
| `AppTopBar` | 二级页返回、标题与必要操作；根层已处理系统栏内边距，避免重复留白 |
| `SettingsPage` / `SettingsCard` | 设置首页和五个独立模块共用分组表面、分隔线、返回与表单样式 |
| `SettingsModule` | 仅保存模块 `key`、`title`、`icon`，由 `key` 派生独立路由；不携带重复说明文案 |
| `RecordTextField` / `SheetTextField` / `PlainField` | 新增与编辑共用 `RecordTextField`，字段 `label` 始终可见；内部 `BasicTextField` 使用同名 `contentDescription`，输入前后都可由读屏与自动化识别，输入热区至少 48dp |
| `SettingsField` | 常驻字段名称、实际输入值、焦点反馈和必要尾部操作；内部 `BasicTextField` 保留 `contentDescription = label` 与至少 48dp 热区，不再呈现输入示例或额外支持说明 |
| `PrimaryButton` | 玫粉主色、主题对应文字色、最小高 52dp、14dp 圆角、按压 98% |
| `SoftCapsuleButton` | 中性控件底、最小高 48dp、默认 12dp 圆角，禁用状态明确 |
| `AddRecordSheet` | 实色表单底、主题遮罩、放弃编辑确认；先按键盘后的可用区域计算高度，约 86%、最大 720dp，内容含标题可滚动，保存区固定 |
| `SyncStatusBar` | 同步中、成功、部分完成或失败；保留原因、时间及重试入口 |
| `PhotoSyncPlaceholder` | 仅显示「照片未同步 / 照片同步失败」；有回调时显示「重试」且整张卡片共用按钮语义，`onRetry = null` 不呈现无响应的操作；大字体可换行 |
| `PhotoImage` / `PhotoViewerDialog` | 保留照片缓存 key、失败占位、分页、双指/双击缩放与可访问关闭按钮 |

内容卡片不模拟玻璃，不靠多层高光和阴影堆叠。真实 Haze 模糊保留给底部悬浮导航；底栏材质从 `AppPalette` 取浅深颜色。

字段名称与用户内容分开呈现，避免输入后丢失字段含义。用户能辨认字段（UX），开发者维护单一组件（DX），智能体能通过稳定语义定位和操作（AX），同时支持读屏；精简文案时保留必要字段名。全部文字继续使用 `FontFamily.Default` 跟随系统字体与字号。

Compose 1.7 的 UIAutomator 导出中，获得焦点的输入框可能将名称放在同一边界的不可聚焦子节点；自动化应同时检查编辑角色、实际值和该唯一名称，不从邻近标签猜测字段，也不为测试清除编辑语义。

## 5. 悬浮底栏与动效

- 保留悬浮胶囊、液态滑块、点按切页、长按拖动、触觉反馈、拖动形变与松手弹簧吸附。
- 三个标签均展示图标和中文文字。底栏宽度受可用空间约束、最大 360dp；默认玻璃高 72dp，并随字体增大适当增高。
- 内容延伸至导航后方作为模糊采样源，各页面通过 `LocalAppBottomInset` 预留末尾可滚动空间。
- 常规按钮按压 98%，列表行用轻微底色反馈；页面使用短位移和淡入。保留滑块的专用弹簧，不添加循环装饰动画。

## 6. 系统主题与状态保持

- 手动切换只改变同一 Compose 树的主题，不替换根导航、不使用 `key(theme)` 或 `Activity.recreate()`。
- 三个主页的展开页头高度与列表位置一同使用可保存状态，避免从设置返回折叠列表时顶部留白归零；主题变化不使这部分几何状态失效。
- `MainActivity` 处理 `uiMode` 配置变化，保留当前页面和未保存内容；`LocalConfiguration` 保持真实系统主题，手动档位不覆盖系统资源配置。
- `WindowChrome` 根据最终主题更新状态栏、导航栏图标和窗口背景。四套启动资源与系统浅深页面底一致。
- 手动档位与机身主题相反时，操作系统创建的启动首帧仍可能沿用机身主题色；本轮不承诺跨所有版本完全消除这段启动色差。

## 7. 图标素材来源

- 13 套主要业务、餐次、设置模块与新增操作素材使用统一的轻立体磨砂材质：灰白与柔粉、轻微体积感、简洁轮廓与克制高光。`ArtworkIcon` 按功能名称统一映射素材；未覆盖的功能符号使用既有原生图标作为回退，不用 emoji 代替功能图标。
- 2026-11-25 新增的磨砂「+」已接入 `ArtworkIcon` 的 `Add` 映射（`R.drawable.art_add`），主页新增与其他通过 `ArtworkIcon` 显示的加号共用这一资源。`新增记录` 等操作描述继续保留，不因换成图片丢失无障碍名称。
- 原图、提示词与来源记录保存在 `output/imagegen/ios-icons/`，以 `manifest.json` 为清单；应用资源位于 `app/src/main/res/drawable-nodpi/`。
- 素材来自原生 `image_gen` 工具。用户指定 Image2，清单中将其记录为请求模型；原生工具未暴露实际模型 ID，不能写成已核验的 Image2 产物。relay 路径检查时没有 API 凭据，不能声称通过 relay 验证了模型。
