# 设计系统：温柔手账 · 奶油纸感

> 状态：奶油纸感已落地；当前版本 4.3.1（versionCode 45）。
> 基准：`deliverables/visual-style-proposal/视觉风格规范.md`；HTML 风格板只作观感参考，冲突以文字规范为准。

## 1. 设计方向

界面是一本两人共写的布面手账：页面是中性米纸，内容是贴上去的纸片，品牌粉只作印泥点缀。材质主题不等于把整屏换色；层次由纸色明度差、1dp 实色纸边、顶缘高光、左缘压痕和程序化纸纤维建立。

- 页面使用纸卡；底部导航按用户要求保留原版悬浮玻璃胶囊与滑动动画，仅底栏使用实时模糊。
- 品牌粉保持 `#C92661`（浅）/ `#E8699C`（深）。
- 粉色只用于主按钮、选中态、FAB、纪念日数字、左缘光、≤20dp 标签底；全屏面积 ≤8%，同屏 ≤3 位。
- 动画、组件名和信息架构保持原样：`GlassCard` 等名称保留，避免视觉迁移牵动业务代码。
- 文案只保留标题、操作、日期、真实内容与必要状态；不加装饰性副标题或重复说明，配置帮助按需展开。

## 3. 字体

- 系统无衬线，不引字体文件；数字使用 Monospace。
- 页面标题 30sp Medium（屏宽 <360dp 时 28sp）；卡片标题 20sp；正文 16sp（行高 26sp）；辅助 14sp；角标 12sp。
- 纪念日数字 48sp Light；`responsiveBigNumeralStyle()` 在 fontScale ≥2 时把最终可视字号限制在 72–88sp，数字独占一行。
- 禁止 700+ 字重、斜体、负字距；图标 Material Outlined 16/20/24dp。

## 4. 形状与间距

- 控件圆角 10；卡片 12；抽屉 / Sheet / 弹层 20；胶囊 999；贴纸 4；胶带 2。
- 贴边侧直角、露出侧 20dp：左侧抽屉右两角 20dp，底部 Sheet 上两角 20dp。
- 页面左右 24、卡内 16、页面级卡间距 20、列表 / 网格内部 8、段落 12、Section 32、页底 48。
- 主按钮 48、次按钮 40（最低热区仍 48）、FAB 56、顶栏 56、底栏视觉 56 / 热区 64、设置行 ≥56、输入 48、分段 48 热区。

## 5. 材质

| 层 | 浅色 | 深色 |
| --- | --- | --- |
| 纸卡 | `#FCF8F1` 100% 不透明 | `#221E1A` 100% |
| 纸边 | 1dp `#E2D6C2` | 1dp `#3B332C` |
| 顶缘高光 | `#FFFCF7` | `#4A4038` @45% |
| 左缘压痕 | `#D6C8B2` | `#14100E` |
| 投影 | 2dp / 暖墨 @8% | 无投影，靠明度差与纸边 |
| 纸纹 | 固定种子散点 @2.5% | 浅墨散点 @3% |

- 纸纹由 `Modifier.paperTexture()` 使用 `drawWithCache` 生成一次；6dp 网格、12dp 纤维线，禁止逐帧随机。
- `paperBackground()` 只铺页面底；卡面由 `glassPanel()` 叠加纸纹，文字永远在纹理之上。
- 装饰：纪念日左缘 3dp 渐变光、右上一条 48×16dp 胶带；空态虚线卡四角十字针脚。装饰不响应指针、不获取焦点、不发声。
- 单级降级出口 `LocalDegradationLevel` 已接入现有装饰：L1 关闭纸纹、L2 关闭纪念日渐变光、L3 关闭胶带、L5 关闭针脚、L7 虚线改实线；200% 字体直接进入 L7。功能、热区、对比度与状态不降级。运行时帧率触发的自动降级尚未接入，需真机性能验收后再启用。

### 六种状态

- **default**：纸卡 / 纸槽 / 粉容器按语义角色取色。
- **hovered**：鼠标或触控板悬停时叠加 6% 纸墨（`paperInk`），不缩放、不位移。
- **pressed**：按钮 98% 缩放；行类、日期格、分段、抽屉行叠加 6% 纸墨；两者不混用。
- **selected**：选中块使用中性抬升底 + 粉边 / 粉字；底栏保留原版半透明粉色液态滑块；抽屉保持中性底，不铺粉。
- **disabled**：实色禁用底 + 实色次文字，语义播报“不可用”；不再用 alpha 0.38。
- **error**：错误底 + 45% 错误边 + 中文原因，不以颜色作为唯一信息。
- **focused**：输入控件 2dp 主色内描边；可点行 2dp 主色焦点框，每屏焦点唯一。

主题级 `LocalIndication` 已切换为空 Node 工厂，M3 默认 ripple 全站关闭；交互反馈只走上述缩放 / 染色 / 震动。

## 7. 主题档位

仍为三档：跟随系统（默认）/ 浅色 / 深色。`ThemeStore.mode` → `resolve()` → `TheCutestGirlTheme`，换档不重建 Activity，表单与滚动位置不丢；系统栏图标与窗口底色由 `MainActivity.applyWindowChrome` 同帧翻转；换档 220ms 淡入，不做交叉溶解。
