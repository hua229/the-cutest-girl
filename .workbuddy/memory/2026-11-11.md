# 2026-11-11

## 新界面视觉风格提案（规范预览，未落地）

- 用户拍板四项：整个 App 视觉换新 /「温柔手账 · 奶油纸感」/ 只交付规范 + 风格板、不改代码 / 全部沿用现有硬约束。先要 plan，确认后才动手。
- 走「UI 设计全栈专家团」正式流程：建团 `ui-cutestgirl`，Phase 1 视觉（frontend-design-architect）→ Phase 2 体验（ux-ui-designer）→ Phase 3 落地与性能（frontend-engineer）→ 主理人汇编；跨成员信息一律由主理人中转。
- 核心结论：**材质主题，不是色彩主题**。浅底 `#F3EDE2`（H39° 中性米纸，无粉相）、深色 `#171412` / `#221E1A` / `#2C2722`（暖黑牛皮纸，无紫）；品牌粉 `#C92661` / `#E8699C` 保持不变，仅 6 个允许位 + 全屏 ≤8% + 同屏 ≤3 位；取消 92% 白玻璃与一切模糊，改 100% 不透明纸卡 + 1dp 实色纸边 + 顶缘高光 + 左缘压痕；底栏 Haze → 64dp 纸质横条。
- **明确不恢复 v4.0 奶油玫瑰 / plum 深色**（AI_HANDOFF 约束 7）。「奶油」指纸基色温，不是玫瑰色相。
- 主理人裁决：去 Haze 属收紧、不违反「Haze 只允许底栏」限制性条款；功能色与中性面登记进 `LocalAppPalette` 属数据登记；`paperInk` 新增字段仅建议、本轮不落代码（回退 `mutedText` 已复算达标）；抽屉阈值 `<320dp` → `≤320dp`；圆角统一「贴边侧直角、露出侧 20dp」；禁用态 alpha 0.38 改实色；分段选中禁沿用旧版 18% 粉底；**本轮不改任何项目正式文档**（`docs/design-system.md`、`AI_HANDOFF.md` 的旧色值字面描述列为落地前需同步项）；不改版本号。
- 体验侧要点：信息结构零新增；键盘弹起时 AddRecordSheet 按 IME 之上可用高度重算（360dp 下限失效、兜底 240dp、<240dp 切同一 Sheet 全屏表单态）；200% 字体写死高度改 minHeight；所有 <48dp 控件补热区；装饰层不发声不可聚焦不消费指针事件；白字白名单收窄 2 处；降级优先级 L1–L8。
- 性能净结论：去 Haze 移除每帧 GPU 模糊，纸纹为一次性静态绘制 + 坐标缓存，净收益为正；验收阈值 overdraw ≤2.0x、`Draw` P95 ≤4ms、掉帧率 ≤1%。
- 交付：`deliverables/visual-style-proposal/视觉风格规范.md`（三阶段汇编 + 裁决记录 + 差异对照 + 风险待定项）、`deliverables/visual-style-proposal/style-board.html`（单文件零依赖、可切浅深、含双份色板/字阶/组件/装饰/五态/降级表）。
- 边界：未改任何 App 代码、版本号、正式文档、依赖与字体文件，未触碰同步与数据语义，未跑编译与回归（因未改代码）。
